Course Curriculum & Syllabus

Module 1: Advanced JavaScript (ES6+)
  • Arrow Functions, Destructuring, Spread/Rest Operators

  • Closures, Scopes, and Module Patterns
Module 2: React.js Frontend Development
  • Components, JSX, Props & State Management
  • React Hooks (useState, useEffect, useMemo, useContext)
  • React Router for Single Page Application navigation
  • State Management using Redux Toolkit / Context API
Module 3: Node.js & Express.js Backend
  • Node.js Runtime & NPM Ecosystem

  • RESTful API Endpoints & Postman Integration

  • NoSQL Concepts, Document Collections & CRUD Operations
  • Mongoose ODM, Schema Validation & Aggregations
  • Full Stack Project Integration & Deployment on Render / Vercel
